Projet SAE – Gestion d'une banque

Présentation

Dans le cadre de ma SAE, j'ai réalisé avec mon binôme une base de données bancaire sur Microsoft Access.

Le but était de créer un système permettant de gérer les différentes informations d'une banque.

Le projet permet de :

Gérer les agences et les banquiers.

Ajouter des clients et leurs comptes bancaires.

Enregistrer les opérations bancaires.

Gérer les prêts et les assurances.

Créer des formulaires et des états pour faciliter la gestion.

Technologies utilisées

Microsoft Access

PowerAMC

SQL

Objectif

Ce projet m'a permis de mieux comprendre la conception d'une base de données relationnelle, notamment la création des tables, les relations entre elles et l'utilisation de requêtes et de formulaires.
